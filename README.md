# Suraj Lakshman — GitHub Pages Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript. No framework, build step or paid hosting is required.

## Before publishing

1. In `index.html`, replace `YOUR_EMAIL@example.com` with the email address you want public.
2. Review the experience descriptions and project wording. The Door Kickers, paid-mobile-game and creator-ecosystem sections are described as research / validation work, not completed campaigns or proven results.
3. If you have public case-study links, add them to the project cards.

## Publish using GitHub Pages

1. Create a public GitHub repository named `suraj-lakshman.github.io` (for the URL `https://suraj-lakshman.github.io/`).
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` directly into the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for deployment; GitHub will show the live site URL in Pages settings.

For a repository with another name, the URL is generally `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Edit the site

- `index.html`: text, links, sections and project descriptions
- `styles.css`: colours, typography, layout and responsive behaviour
- `script.js`: mobile navigation and footer year

Google Fonts are loaded from Google Fonts. If unavailable, the page falls back to system fonts.
